# The Frightened Dryad

The separate Blighted Grove quest giver uses body 266 and neutral hue, with the existing Dryad model. Her original tile is (6500, 875, 0) on both Trammel and Felucca. The extension follows the project's existing command-based placements. An administrator runs PlaceFrightenedDryad near that tile on each facet. The command checks the region and tile, places one spawner, and refuses duplicate placement. The original references specify one spawn, zero range and a five- to ten-minute respawn delay.

Bound to the Land requires 12 Insane Dryads and one Saliva inside the Grove. The native turn-in awards Dryad's Blessing with graphic 0x021C, authored reference hue 0x0488, localized name 1074345, and the seven-day lifetime inherited from the pinned PeerlessKey. The observed native timer check accelerated expiry in the disposable trial. The basket and Lady Melisande admission require separate work.

Two disposable clients received the invulnerable body 266. The test checked both placements, duplicate prevention, conversation range, refusal of outside kills, both required objectives, standard gump turn-in and the reward. Both NPC placements and the reward survived restart. The reward expired with its normal message and left the backpack. The final native trial passed 40 initial and 20 restart checks. The fixture placed the players, supplied the quest mobs and dealt lethal damage. No corpse is expected from this invulnerable quest giver.
