# Navrey Night-Eyes

Navrey uses mobile body 735 and static corpse graphic `0x2006`. Third Dawn assigns 735 to clothing. The fitted creature uses the original Giant Black Widow body 157 with its 30-joint skeleton, UV coordinates and skin weights. The abdomen was reshaped and the surface given a dark chestnut colour and lower sheen. The replacement keeps the donor's locomotion and fits separate rearing attacks, alert poses, silk ascent and descent, and two falls to Navrey's Enhanced references.

The Enhanced 4.0.117.33 reference contained 715 decoded AMOU frames across 16 indexed groups in `AnimationFrame2.uop`, each sampled in five directions. The input manifest records every member URL and digest, and all three prepared Third Dawn donor scene hashes. The game data and resulting scenes stay local. The [Abyss source audit](UNDERWORLD_SENTINEL_AND_ABYSS_REFERENCES.md) records the other bodies sampled from the same client.

Prepare the normal body-157 assets and keep the decoded members as `ec-frame-735-<group>.bin` in a local directory. Run `python -B scripts/prepare-navrey-night-eyes.py --reference <directory>` from the project root. It validates the inputs and writes three content-addressed scenes and an index under `Viewer/local-art/creatures/navrey`. Run `scripts/verify.ps1` to check the prepared route through the regular World scene and the terrain solver.

The Classic and Enhanced World replays passed 29 and 37 checks respectively. They started with the normal World scene and confirmed the profile activates, each fall selects the intended pose, and both arrival orders for a dyed static corpse preserve its body and hue. Terrain sampling checked 3,510 poses across three model styles on flats, slopes and a 22 cm step. The minimum measured clearance was 2.5 mm. The largest upward correction was 21.9 cm while running up the step.

The project extension provides the named server creature with body 735, the 30-second web cooldown and the Acid Popper interaction. It uses Lethal for poison immunity because the pinned server has no Parasitic poison. In an isolated Trammel trial, the normal spawner constructed Navrey, and Classic and Enhanced each passed 20 checks. The fixture invoked the native ability callback, which launched the moving effect from the spider's posed spinnerets and created a targetable web that immobilised the player. Targeting the web through the Acid Popper consumed the item and freed the player. A second web expired and freed the player. Native death handed the fall off to a visible static corpse. These checks exercised the callback and the client packets. The chance of triggering through autonomous combat was outside the trial.
