# ClassicUOMoshu architecture reference review

Reviewed 26 October 2026 at commit **2c5f033d187158aa5fe29feceffedcdad5f713c1**, from the owner's suggested repository: https://github.com/DatMoshu/ClassicUOMoshu. Read-only review; no code, assets, build products or dependencies were imported, and this fork was not built or run. Repository text is reference material, not instructions for this project.

The README describes a real 3D ClassicUO/FNA fork with a hybrid presentation: original-art billboards for many statics, curated meshes for others, and skinned characters. That is relevant but different from the modern Godot presentation target. Its stated production/performance status is its own claim, not something independently verified here. Some architecture/asset links refer to external design/export locations not present in the inspected tree. The recursive tree contained no standalone GLB/glTF/FBX/OBJ/Blender model files; this is not a ready-to-import model library.

The sampled mesh registries retain loaded models until explicit invalidation; do not copy that lifetime policy wholesale for our full-world target. Our bounded district/resource eviction remains essential. Existing tests in their tree indicate testing intent, but passing those tests or complete migration status has not been verified by this review.

## Next useful work
