## Build and verify

Use a local install of the reviewed Classic and Enhanced archives. Build with the donor body in the input catalogue already prepared. Prepare the pinned CC0 Raptor donor with `scripts/prepare-raptor.py` for body 716.

```powershell
python -B scripts/prepare-later-creatures.py --sequence <AnimationSequence.uop> --classic <Classic-data-folder>
```

Pass one or more `--body` flags to build only those bodies. The preparer checks the Enhanced sequence and all selected Classic member hashes. Each original rig baker checks the registered donor hash. The recipe writes each compressed scene once under its content hash. The manifest is replaced only after the selected builds succeed. Local assets and reference frames stay in ignored directories.

Use `scripts/test-later-creature-world.gd` with the numeric `--body` listed above, in Classic and with `--enhanced-creature-actions`. The viewer loads each prepared body independently after checking all three scene hashes. The separate `scripts/test-forgotten-servant-world.gd` runs both human bodies.
