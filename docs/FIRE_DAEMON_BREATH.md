# Fire Daemon breath

The project's native Fire Daemon uses body 9 and hue 1636. It shares the retained Third Dawn Daemon model, while Fire Daemon Renowned uses body 40 and has a different ability set. The exact five-frame Classic group 12 cue and hue 1636 select a longer breath fitted from the existing `DaemonCast` on the original rig. Ordinary Daemon casts stay on their usual route.

The firebolt leaves the point fitted to the head by the mouth. The client preserves the windup when the same creature sends an overlapping melee cue. A fall can interrupt the animation and transfer to the frozen corpse with the server hue. The Forward+ review confirmed the anchor at the mouth. The Daemon rig has no separate jaw animation for this action.
