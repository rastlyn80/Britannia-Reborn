# Server-driven environment

Britannia Reborn now consumes native ModernUO global light (0x4F), personal light (0x4E) and weather (0x65) packets. Server values control sunlight/ambient readability, rain or snow density, cloud cover and fog. Clear FE/FF values stop precipitation; unsupported weather types do not invent storms. Personal light affects readability independently of the time of day.

## Regional clock bridge

The pinned ModernUO Clock.GetTime implementation uses its own epoch, facet offset and X-region offset, with five real seconds per UO minute. Standard weather/light packets do not contain that clock. The isolated, enabled preview extension adds a loopback-only, read-only PreviewEnvironment command. Godot requests it every ten seconds, without movement resync. It returns a versioned UCENV1 system message containing hours, minutes and the upstream minute rate, then resends native light and a current weather snapshot for that mobile.

The client accepts the clock prefix only from system-serial messages, checks numeric ranges, interpolates regional time between samples and stops extrapolating after 30 seconds without another sample. Clock precision is one upstream minute, not exact sub-second phase. Disconnect restores the fixed afternoon offline preview and clears the connected state. Existing camera and movement reconciliation are unaffected.

The scheduler has no public current-weather snapshot API. The extension reads three private state fields from the pinned Weather type, on the main game loop, and combines applicable active areas using the greatest precipitation density. The density uses the last completed upstream stage. This also clears precipitation after leaving an active weather area, something the scheduler's event packets alone do not guarantee immediately. Missing fields on a dependency upgrade produce an explicit error. This adapter needs review when changing the server pin; it does not modify weather, regions, the server clock, accounts or permissions.

## Presentation

A code-generated seamless noise texture supplies softly moving clouds. The shader adds a horizon gradient, sunlight glow and night sky. The daylight curve follows upstream LightCycle's long daytime hours: dawn 04–06 and dusk 22–24. Global light also respects server darkness overrides. Local clock time determines sky direction; a dungeon/global override darkens the scene without changing astronomical time.

Weather transitions are eased. Camera-local lightweight rain/snow geometry follows server density. An upward collision query hides precipitation under the camera's building ceiling; it is not per-drop roof collision or a weather physics simulation. Fog and cloud darkness respond to precipitation. Uniform updates are limited to 2 Hz; wind/water animations remain presentation effects. There are no independently generated random weather changes, forecast, lightning, audio, snow accumulation or persistent wet-surface system.

These are shared client/server integration rules and therefore apply to future converted areas. New region coverage and streamed geometry still need validation. The pretty-sky geometry is independent artwork generated by code, with no proprietary game textures.

## Reproduce

- scripts/verify.ps1: includes 13 new protocol/environment checks, malformed payload rejection, midnight rollover, fragmented packets and state reset.
- scripts/test-environment.ps1: actual development-character entry and clock/light/weather receipt. Existing character and local server required.
- scripts/capture-environment.ps1: controlled day, night, rain and snow screenshots, plus GPU checks for day/night contrast, cloud movement and real-building shelter. Add -Compatibility for the OpenGL renderer.
- Screenshots remain local under outputs/validation/environment-*.png. Controlled weather captures are fixtures, not claims that the live shard was raining or snowing.
