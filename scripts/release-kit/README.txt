BRITANNIA REBORN - friends' test build
======================================

A private test build of a 3D client for Ultima Online, with its own game
server. It is for the friends helping to test it; please do not pass it on
(it contains Ultima Online game data, which belongs to Electronic Arts).

Start
-----
1. Unzip the whole folder somewhere with about 30 GB free (not inside
   "Program Files").
2. Double-click Play.cmd.
   The first start takes a minute or two: the game server starts in the
   background, then the game opens.
3. Sign in with
     Account:  {USERNAME}
     Password: {PASSWORD}
   and choose the character "Tester". It is an administrator: the whole of
   Trammel is yours to explore, populated with monsters, vendors and
   moongates.

Everything runs on your own computer; nothing connects to the internet.

Useful
------
- Esc: the game menu. Developer > Travel takes you to any town, dungeon
  or shrine. Developer > Die / Resurrect shows the ghost world.
- Esc > Keys and help lists the keys (W A S D to walk, Shift to run).
- Tap V for voice chat (needs speech recognition set up; optional).
- Stop Server.cmd stops the game server when you are done (the world saves
  itself every few minutes).

Feedback
--------
Note what you saw, where (the coordinates shown at the top of the screen)
and a screenshot if you can, and send it back. Thank you for testing!
