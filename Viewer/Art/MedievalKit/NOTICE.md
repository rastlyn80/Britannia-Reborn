# MedievalKit modules

Selected static modules of MedievalKit 5.1.1 (CC0 1.0 Universal; full text in LICENSE.txt, material provenance in CREDITS.md, which credits ambientCG CC0 materials). Exported from the owner-supplied MedievalKit.blend with Blender 5.2.1 by scripts/export-medievalkit.py; colour and roughness maps re-encoded as JPEG, geometry unchanged. manifest.json records the source file hash, module triangle counts and the SHA-256 of every file here. Optional credit: "MedievalKit, CC0. Includes materials derived from ambientCG."
